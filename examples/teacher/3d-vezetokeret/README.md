# 3D: forgó vezetőkeret mágneses térben / 3D: rotating loop in a magnetic field

## Magyar

Forgó vezetőkeret homogén mágneses térben, 3D nézetben. Képletek: `Φ = B·A·cos α` és `u = −N·dΦ/dt = N·B·A·ω·cos θ`, ahol α az n normálvektor és B szöge (`α = θ + 90°`). A nézet szöge csúszkával forgatható.

## English

A rotating loop in a uniform magnetic field, in a 3D view. Formulas: `Φ = B·A·cos α` and `u = −N·dΦ/dt = N·B·A·ω·cos θ`, where α is the angle between the normal n and B (`α = θ + 90°`). Sliders turn the view.

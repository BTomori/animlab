## Magyar

Háromfázisú rendszer csillag (Y) vagy delta (Δ) terheléssel. Képletek: `u_k = √2·U_f·sin(ωt − k·120°)`, `U_v = √3·U_f`, `Ī = Ū / Z`, `Z = R + jX`. Csillagban `Ī_N = Ī₁ + Ī₂ + Ī₃`, deltában a vonali áram `Ī₁ = Ī₁₂ − Ī₃₁`. A három fázis ellenállása külön állítható, így aszimmetrikus terhelés is kipróbálható.

## English

A three-phase system with a star (Y) or delta (Δ) load. Formulas: `u_k = √2·U_f·sin(ωt − k·120°)`, `U_v = √3·U_f`, `Ī = Ū / Z`, `Z = R + jX`. In star `Ī_N = Ī₁ + Ī₂ + Ī₃`, in delta the line current is `Ī₁ = Ī₁₂ − Ī₃₁`. The resistance of each phase is set separately, so an unbalanced load can be tried too.

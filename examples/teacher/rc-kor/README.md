## Magyar

Kondenzátor töltése ellenálláson keresztül (RC kör). Képletek: `i = (U − u_C) / R`, `C · du_C/dt = i`, `u_C(t) = U · (1 − e^(−t/τ))`, `τ = R·C`. A kapcsolási rajz IEC jeleket használ.

## English

Charging a capacitor through a resistor (RC circuit). Formulas: `i = (U − u_C) / R`, `C · du_C/dt = i`, `u_C(t) = U · (1 − e^(−t/τ))`, `τ = R·C`. The schematic uses IEC symbols.

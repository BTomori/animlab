# Ütközés (lendület, energia) / Collision (momentum, energy)

## Magyar

Egyenes ütközés lendület- és energiamérleggel. Képletek: `m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'`, `e = (v₂' − v₁') / (v₁ − v₂)`. A tömegek, a sebességek és az ütközési szám csúszkával állíthatók.

## English

A head-on collision with momentum and energy balance. Formulas: `m₁v₁ + m₂v₂ = m₁v₁' + m₂v₂'`, `e = (v₂' − v₁') / (v₁ − v₂)`. The masses, the speeds and the coefficient of restitution are set with sliders.

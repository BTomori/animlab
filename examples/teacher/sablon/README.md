# Sablon: alakzatok, képek, fizika / Template: shapes, images, physics

**[▶ Megnyitás az AnimLab-ben / Open in AnimLab](https://btomori.github.io/animlab/?scene=examples/teacher/sablon)** · jelenetfájl / scene file: [`scene.animlab.json`](scene.animlab.json) · [média / media](media/)

## Magyar

Kiindulópont saját jelenethez: alakzatok, feltöltött kép és fizikai világ egy rövid, kommentezett jelenetben. A szkript felülről egyszer fut le (és minden újraindításkor); a `param`, `toggle` és `button` a vezérlőket hozza létre, az `update` a fizikát számolja, a `draw` rajzol. Ez ugyanaz a jelenet, amellyel a program indul, ha nincs automatikusan mentett jelenet.

## English

A starting point for your own scene: shapes, an uploaded picture and a physics world in one short, commented scene. The script runs once from the top (and again on every reset); `param`, `toggle` and `button` create the controls, `update` computes the physics, `draw` draws. It is the same scene the app starts with when there is no autosaved scene.

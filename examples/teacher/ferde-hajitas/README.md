# Ferde hajítás / Projectile motion

**[▶ Megnyitás az AnimLab-ben / Open in AnimLab](https://btomori.github.io/animlab/?scene=examples/teacher/ferde-hajitas)** · jelenetfájl / scene file: [`scene.animlab.json`](scene.animlab.json) · [média / media](media/)

## Magyar

Ferde hajítás, választható légellenállással és visszapattanással. Képletek: `x = v₀·cos α·t`, `y = h + v₀·sin α·t − g·t²/2`. A kezdősebesség, a szög, a magasság és a nehézségi gyorsulás csúszkával állítható.

## English

Projectile motion with optional air drag and bouncing. Formulas: `x = v₀·cos α·t`, `y = h + v₀·sin α·t − g·t²/2`. The initial speed, the angle, the height and the gravitational acceleration are set with sliders.

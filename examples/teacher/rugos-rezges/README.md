# Csillapított rugós rezgés / Damped spring oscillation

## Magyar

Csillapított rugós rezgés. Képletek: `m·a = −k·x − b·v`, `f₀ = √(k/m) / 2π`, `E = ½·k·x² + ½·m·v²`. Az x a nyugalmi helyzettől mért kitérés (lefelé pozitív); a súlyerőt a nyugalmi helyzet már kiegyenlíti.

## English

Damped spring oscillation. Formulas: `m·a = −k·x − b·v`, `f₀ = √(k/m) / 2π`, `E = ½·k·x² + ½·m·v²`. x is measured from the rest position (down is positive); gravity is already balanced at the rest position.

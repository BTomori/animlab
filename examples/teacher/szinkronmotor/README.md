# Szinkronmotor / Synchronous motor

## Magyar

Szinkronmotor egyenárammal gerjesztett, hengeres forgórésszel. Képletek: `M = 3·U_f·E₀ / (ωₛ·X_d) · sin δ` (a csillapító kalicka nyomatékával kiegészítve), `Ī = (Ū − Ē₀) / (jX_d)`, ahol δ a terhelési szög.

## English

A synchronous motor with a DC-excited cylindrical rotor. Formulas: `M = 3·U_f·E₀ / (ωₛ·X_d) · sin δ` (plus the damper cage torque), `Ī = (Ū − Ē₀) / (jX_d)`, where δ is the load angle.

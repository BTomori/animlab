## Magyar

Az 1 + 2 + … + N összeg algoritmusa folyamatábrán, lépésenként. Az aktív blokk és az utoljára bejárt nyíl narancssárga, a változók értéke jobb oldalt látszik. A blokkok egy listában vannak (hely, alak, szöveg, utasítás, következő blokk), így a példa könnyen átírható más algoritmusra.

**Kipróbálásra:** N billentyű = következő lépés, A = automatikus futás. Kérdezd meg a diákokat, hányszor fut le a ciklus N = 5 esetén.

## English

The algorithm of 1 + 2 + … + N as a flowchart, step by step. The active block and the arrow just taken are orange; the variables are on the right. The blocks are in one list (place, shape, text, statement, next block), so the example is easy to rewrite for another algorithm.

**Try this:** Key N = next step, A = automatic run. Ask the students how many times the loop runs for N = 5.

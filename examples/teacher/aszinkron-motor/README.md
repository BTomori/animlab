## Magyar

Aszinkron (indukciós) motor kalickás forgórésszel, közelítő helyettesítő kapcsolással fázisonként, csillagkapcsolásban. Képletek: `s = (nₛ − n) / nₛ`, `M = 3·I₂'²·R₂' / (s·ωₛ)`, `J·dω/dt = M − M_t`. A terhelőnyomaték a W / S, a forgásirány a V billentyűvel is állítható, az Enter újraindít.

## English

An induction motor with a squirrel-cage rotor, using an approximate per-phase equivalent circuit in star connection. Formulas: `s = (nₛ − n) / nₛ`, `M = 3·I₂'²·R₂' / (s·ωₛ)`, `J·dω/dt = M − M_t`. The load torque also works with W / S and the direction with V; Enter restarts.

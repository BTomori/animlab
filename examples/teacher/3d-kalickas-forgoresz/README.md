# 3D: kalickás forgórész forgó mezőben / 3D: cage rotor in a rotating field

## Magyar

Kalickás forgórész forgó mágneses mezőben, 3D nézetben (p = 1). A rudakban csak akkor indukálódik áram, ha a mező gyorsabban forog, mint a forgórész (s > 0). A nézet szöge csúszkával forgatható.

## English

A squirrel-cage rotor in a rotating magnetic field, in a 3D view (p = 1). Current is induced in the bars only while the field turns faster than the rotor (s > 0). Sliders turn the view.

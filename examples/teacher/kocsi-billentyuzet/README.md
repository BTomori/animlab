# Kocsi nyilakkal (billentyűzet) / Cart with the arrow keys (keyboard)

## Magyar

Kocsi billentyűzettel, Newton II. törvénye: `F_motor − F_ellenállás = m · a`. A ← → hajt, a Szóköz nyomva tartva fékez, az M jelölőt tesz le, a W / S a motorerőt állítja. Telefonon ugyanezek gombként jelennek meg a vásznon.

## English

A cart driven from the keyboard, Newton's second law: `F_motor − F_resist = m · a`. ← → drive, holding Space brakes, M drops a marker, W / S set the motor force. On a phone the same keys appear as buttons on the canvas.

# Forgó fázor és szinuszgörbe / Rotating phasor and sine wave

## Magyar

Forgó fázor és a szinuszgörbe. A fázor függőleges vetülete minden pillanatban a feszültség pillanatértéke. Képletek: `u(t) = Û · sin(ωt + φ)`, `ω = 2πf`, `U = Û / √2`.

## English

A rotating phasor and its sine wave. The phasor's vertical projection is the instantaneous voltage at every moment. Formulas: `u(t) = Û · sin(ωt + φ)`, `ω = 2πf`, `U = Û / √2`.

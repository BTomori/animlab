# Forgórész fényképről (képhasználat) / Rotor from a photo (using pictures)

**[▶ Megnyitás az AnimLab-ben / Open in AnimLab](https://btomori.github.io/animlab/?scene=examples/teacher/forgoresz-fenykep)** · jelenetfájl / scene file: [`scene.animlab.json`](scene.animlab.json) · [média / media](media/)

## Magyar

Egyenáramú motor forgó forgórész-fényképpel. A példa a jelenetfájlban lévő „rotor” képet használja. Saját képhez a Képek fülön töröld vagy nevezd át a régit, és tölts fel egy homlokképet „rotor” néven. A kép közepe legyen a tengely; ha nem az, állítsd a forgáspontot, és ellenőrizd a „Forgáspont mutatása” kapcsolóval.

## English

A DC motor with a rotating rotor photo. The example uses the picture "rotor" inside the scene file. For your own picture, delete or rename the old one on the Images tab and upload a front view named "rotor". Its centre should be the shaft; if it is not, set the pivot and check it with the "Show pivot" switch.

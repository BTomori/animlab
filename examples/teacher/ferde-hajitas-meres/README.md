# Ferde hajítás: mérés és elmélet / Projectile: measured vs. theory

## Magyar

Ferde hajítás légellenállás nélkül: mért és elméleti érték egymás mellett. Képletek: `H = (v₀·sin α)² / 2g`, `D = v₀²·sin 2α / g`, `T = 2·v₀·sin α / g`. Új kezdőfeltétel beállításakor új hajítás indul.

## English

Projectile motion without air resistance: measured and theoretical values side by side. Formulas: `H = (v₀·sin α)² / 2g`, `D = v₀²·sin 2α / g`, `T = 2·v₀·sin α / g`. Setting a new initial condition starts a new throw.

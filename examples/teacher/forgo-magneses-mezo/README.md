## Magyar

Forgó mágneses mező három, 120°-onként elhelyezett tekerccsel. Képletek: `i_k = Î·sin(ωt − k·120°)`, `B = B₁ + B₂ + B₃`, `|B| = 1,5·B̂`, `n_s = 60·f / p`.

## English

A rotating magnetic field from three coils placed 120° apart. Formulas: `i_k = Î·sin(ωt − k·120°)`, `B = B₁ + B₂ + B₃`, `|B| = 1.5·B̂`, `n_s = 60·f / p`.

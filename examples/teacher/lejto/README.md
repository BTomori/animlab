# Lejtő súrlódással / Inclined plane with friction

## Magyar

Lejtő súrlódással, az erők felbontásával. Képlet: `a = g·(sin α − μ·cos α)`, ha `tg α > μ`. A szög, a súrlódási együttható, a tömeg és a nehézségi gyorsulás csúszkával állítható.

## English

An inclined plane with friction, resolving the forces. Formula: `a = g·(sin α − μ·cos α)`, if `tan α > μ`. The angle, the friction coefficient, the mass and the gravitational acceleration are set with sliders.

# Pattogó labda / Bouncing ball

## Magyar

Pattogó labda. A visszapattanás után `v' = e·v`, és `h = v²/2g`, ezért `h₁ = e²·h₀`. Az ejtési magasság és az ütközési szám csúszkával állítható; új érték beállításakor új ejtés indul.

## English

A bouncing ball. After a bounce `v' = e·v`, and `h = v²/2g`, so `h₁ = e²·h₀`. The drop height and the coefficient of restitution are set with sliders; a new value starts a new drop.

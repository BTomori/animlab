## Magyar

Egyenáramú motor egy tekerccsel és kétszegmenses kommutátorral. A feszültség, a tekercs adatai és a terhelés csúszkával állíthatók. Képletek: `k = N·B·A`, `e = k·ω·|cos θ|`, `I = (U − e) / R`, `M = k·I·|cos θ|`, `J·dω/dt = M − M_terh − b·ω`. A forgórész fényképe a jelenetfájlban van.

## English

A DC motor with a single coil and a two-segment commutator. The voltage, the coil data and the load are set with sliders. Formulas: `k = N·B·A`, `e = k·ω·|cos θ|`, `I = (U − e) / R`, `M = k·I·|cos θ|`, `J·dω/dt = M − M_load − b·ω`. The photo of the rotor is inside the scene file.
